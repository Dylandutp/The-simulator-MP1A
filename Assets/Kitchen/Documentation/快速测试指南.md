# Kitchen 快速测试指南

厨房包含烤鸡、煎牛排和果蔬沙拉。操作已按 Quest 2 / Quest 3 的左右任一单手，以及 PC 键鼠设计；双手可以更方便地传递物品。

## 1. 启动

**Unity 编辑器：** 使用 **Unity 6000.5.6f1** 打开本项目，等待资源导入完成。在 Project 面板打开 `Assets/Kitchen/Scenes/KitchenEntry.unity`，点击 Play，再点一下 Game 窗口让它接收键鼠输入。入口会自动加载共享 MasterScene 和 Kitchen 房间。

**Windows 独立版：** 启动 `Builds/Windows/Kitchen.exe`。本次连续拖动操作修改后已重新构建成功，并通过启动检查。双击启动；移动或分享时保留同目录的数据文件和 DLL，不能只复制 exe。

**Quest 安装包：** `Builds/Quest/Kitchen.apk`（ARM64 / OpenXR）已按本次修改重新构建，签名和 VR 清单检查通过，仍需头显实测。连接已开启开发者模式的 Quest，允许 USB 调试，在项目根目录运行：

```powershell
adb devices
adb install -r ".\Builds\Quest\Kitchen.apk"
```

确认设备列表显示 `device`，安装成功后从头显应用列表的未知来源中打开 Kitchen。连接或安装成功不等于已经通过实机操作测试。

## 2. 操作表

VR 表中的“握柄”指侧面的抓握键，“扳机”指食指按下的键；均使用当前这一只手柄即可。

| 操作 | Quest 2 / Quest 3，左手或右手均可 | PC 键鼠 |
| --- | --- | --- |
| 移动 | 摇杆向前推，指向空地，松开摇杆确认瞬移 | W、A、S、D |
| 转向／看四周 | 摇杆向左／右拨动，分段转向 45°；转头观察 | 按住鼠标右键移动鼠标 |
| 取消瞬移 | 瞬移瞄准时按握柄，再松开摇杆 | 不需要 |
| 拿起／放下 | 握柄抓取，松开握柄放下 | 鼠标指针对准物品点左键，再点左键放下 |
| 开／关冰箱、烤箱 | 按住握柄抓住把手，沿铰链方向拉动，松开停止 | 把手上按住左键，沿门的转动轨迹拖动；松开停止 |
| 调整旋钮 | 按住握柄抓住旋钮并连续旋转，顺时针增加、逆时针减少 | 旋钮上按住左键，绕旋钮中心画圆；顺时针增加、逆时针减少 |
| 开／关水龙头 | 按住握柄抓住拨杆，沿铰链方向拨动 | 拨杆上按住左键并拖动 |
| MIX、建造按钮 | 对准按钮按下并松开握柄 | 对准按钮点左键，也可按 E |
| 切果蔬 | 先把果蔬放在砧板，再抓刀切过它 | 手持果蔬按 C，切块会落在原位置 |
| 吃成品 | 保持握柄，拿到头显附近约 30 厘米内，再按同手扳机 | 手持成品按 F |
| 调整手持距离 | 移动手臂 | 手持物品时滚动滚轮；只改变距离 |
| 扶正翻倒的锅／盘 | 拿起后转正再放下 | 手持时按 R，随后保持水平，便于放置 |

PC 平时用**自由鼠标指针**指向物品；按住右键看四周时，改用中央准星。按住左键拖控件期间，视角和玩家保持不动、指针可见，松开左键结束。旋钮要绕中心画圆，门与水龙头要拖把手／拨杆；仅点击或按 E 不会自动开关，滚轮也不调旋钮。E 只用于 MIX、建造等按钮。按 Esc 取消当前控件拖动并释放鼠标。

拿起的食物或工具跟随视角前方；按住右键瞄准放置位置，用滚轮微调距离，再点左键放下。操作门或旋钮前，先把手上的物品放好。

单手时，先把当前物品放在台面，再操作门、旋钮或换工具。远距离选中物品后，摇杆可能临时用于调整该物品；先把它放好，再瞬移或转向。两只手柄不需要同时按键。

房间已扩大到 **12×10 米**，扩建格位于左侧。体力 HUD 固定在视角左上方，墙上库存板仅显示食材。掉到地板下方会自动回到房间入口，并解除当前抓取。大型教学黑板和烤箱计时显示板已经移除；烤箱旋钮会随倒计时逆时针回转，用旋钮刻度判断剩余时间。

## 3. 三道菜怎么做

### 烤鸡

1. 打开冰箱，拿一只鸡。打开烤箱，把鸡放到内部烤架上并松手。
2. 关好烤箱门，用旋钮设置 **25–30 秒**作为第一份成功烤鸡的练习时间。旋钮可在 **0–60 秒连续调整**，没有固定档位；计时期间旋钮会随剩余时间回转。
3. 等计时结束，听到提示音后开门拿出。观察浅色、金黄或焦黑的外观，再食用查看体力变化。

开门会暂停加热与倒计时，关门继续；已累计的烹饪时间不会因为开门清零。再次加热熟鸡仍会继续累计，可能烧焦。鸡拿在手上或不在烤箱内部时不会加热。

PC 放鸡时先开门，对准烤箱内部，用滚轮调整距离，放到烤架上再关门。

### 煎牛排

1. 从冰箱拿牛排，把平底锅正放在电磁炉红圈位置。锅可以一直放在炉上，不必端着它。
2. 把牛排放入锅内并松手。旋钮调到 **50% 火力**，先练习煎约 **10–12 秒**后关火取出。
3. 火力在 **0–100% 连续调整**：越大，圆圈越红，牛排变熟越快。0% 关闭，50% 为基准速度；此时第 8–17 整秒为刚好，累计达到 18 秒开始焦黑。

只有“锅放稳在炉圈上，牛排放在锅内”才加热。直接放在电磁炉表面的牛排不会熟；拿起锅或取出牛排会停止加热。PC 把锅弄翻时，拿起按 R，再放回炉圈。

| 火力 | 开始达到合适熟度 | 开始焦黑 |
| --- | ---: | ---: |
| 25% | 16 秒 | 36 秒 |
| 50% | 8 秒 | 18 秒 |
| 100% | 4 秒 | 9 秒 |

火力和烹饪速度成线性关系。表内时间假设从生牛排开始、全程保持同一火力；中途改火力不会清空已经累计的进度。

### 果蔬沙拉

1. 从冰箱选择番茄、生菜、苹果中的**至少两种不同食材**。
2. 先开水龙头，把每份食材放在流水区域累计冲洗 **3 秒**，观察清洁提示。
3. 放到砧板切开。VR 用刀，PC 可拿着按 C；先切后洗也可以。
4. 将切好的食材放进沙拉碗并松手，每种放一份，然后操作 **MIX** 按钮。
5. 拿起生成的沙拉食用。只要其中一份未洗干净，整份沙拉都会扣体力。

原状果蔬不能直接当成品吃，也不能跳过切配投入碗中。未满两种食材时，MIX 会提示不足并保留碗内材料。

## 4. 体力结果

首次初始化为 **70 / 100**，最小 0、最大 100；同一次游戏重新加载厨房会保留共享体力。以下均为游戏内加速时间。

| 食物状态 | 判定 | 体力变化 |
| --- | --- | ---: |
| 鸡：时间过短 | 累计不足 20 秒，颜色浅 | -15 |
| 鸡：刚好 | 累计 20 秒以上、不满 40 秒，金黄 | +30 |
| 鸡：烧焦 | 累计达到 40 秒，焦黑 | -20 |
| 牛排：时间很短 | 不足 8 等效秒 | +5 |
| 牛排：刚好 | 8 等效秒以上、不满 18 等效秒 | +25 |
| 牛排：烧焦 | 达到 18 等效秒 | -15 |
| 沙拉：全部洗净 | 所有加入食材完成清洗 | +20 |
| 沙拉：有脏食材 | 任一加入食材未完成清洗 | -15 |

牛排的“等效秒”已在上方火力表换算成实际等待时间。测试加体力时留意 100 上限，例如 90 体力吃 +30 的食物，结果为 100。

## 5. 补货、垃圾与建造

- **所有原料从冰箱拿。** 每次开门或关门都会补充空位，已经拿出的食材不会被刷新掉。冰箱还会随机间隔 12–20 秒补一个空位。
- 不要的食材放进烹饪台旁的垃圾桶后**松手**，才会丢弃；不会因此增加体力。锅、刀和搅拌碗不会被当垃圾删除。
- 拓展区先在墙面选择 **BASE**，再选择地面的 **BUILD** 格子；然后选择设备，在同一格子建造。没有基础或格子已占用会拒绝放置。此版建造免费。
